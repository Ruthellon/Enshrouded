About this data

Node names, colours and connection rules come from the game. Each node shows its slots: inputs on the left, the output on the right. Two-input nodes have an upper and a lower input slot, and orange links go into the LOWER one (the file stores UPPER as input slot 0 and LOWER as slot 1). Dropping a link on a node body, not a slot, uses the first free input. Save and Use Signal channels and the time values are decoded from each node’s extra data. A World Object shows the name you gave its object in the game (read from the save; only some object types are known by name). Logic gates are drawn as their usual symbols. Green dashed links and rings are new, and yellow dashed rings mark nodes you moved or changed.
